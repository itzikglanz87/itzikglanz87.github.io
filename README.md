# itzikglanz87.github.io

The root of this GitHub Pages address. It holds one thing that matters:
`.well-known/assetlinks.json`, which tells Android that the app
`io.github.itzikglanz87.fifatournament` belongs to this site, so the app
opens full screen without an address bar. `.nojekyll` makes Pages serve the
`.well-known` folder. `index.html` sends visitors to the app at
[/fifa-tournament/](https://itzikglanz87.github.io/fifa-tournament/).
